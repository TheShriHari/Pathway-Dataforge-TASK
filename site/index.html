Autoregressive Chain-of-Thought

Scales test-time compute by generating external natural-language tokens (e.g. “First, let’s inspect cell (1,2)...”). This verbalization increases context length quadratic attention memory, incurs KV-cache storage overhead, and risks cascading token drift.

Recurrent Latent Reasoning

Scales test-time compute by repeatedly iterating a shared-weight core over continuous high-dimensional latent states $h_k = \text{Core}(h_{k-1}, x)$. It uses zero extra token bandwidth, maintains a constant memory footprint, and refines solutions purely through tensor depth.

Explicit Model Limitations

  • Task Dimensionality: 2D grid mazes are spatial pathfinding problems. While spatial connectivity models receptive field expansion, language reasoning requires abstract relational composition.
  • Receptive Field Saturation: Beyond the maze diameter ($K \ge 5$), the physical receptive field covers the entire grid. Additional loops only refine edge confidence, resulting in the observed plateau.
  • Static Client Substrate: All interactions replay precomputed traces to ensure zero latency, zero backend dependencies, and 100% judge reproducibility without API keys or GPUs.
