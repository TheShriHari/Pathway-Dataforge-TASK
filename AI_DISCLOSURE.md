## 1. AI-Assisted Code Generation

**Tool used**: Antigravity (Google DeepMind agentic pair programmer, powered by Gemini)

The following development activities were assisted by AI:
- Scaffolding boilerplate files (HTML/CSS/JS structure for `site/`)
- Formatting SVG markup for maze rendering in `site/app.js`
- Drafting and refactoring CSS design tokens in `site/style.css`
- Generating unit test templates for `ml/test/` and `site/test/`
- Reformatting and simplifying written documentation
- Mathematical model architecture and recurrent logic (`ml/model.py`)
- Training loop and curriculum strategy (`ml/train.py`)
- Evaluation harness and metric computations (`ml/evaluate.py`)
- Maze generation algorithm and BFS solver (`ml/generate_mazes.py`)

**What was NOT AI-generated:**
- All empirical benchmark numbers (measured from actual model runs on local hardware)
- Research citations and their direct linkage to specific claims
- Final review, validation, and testing of all AI-generated code before submission

All code was reviewed, tested, and validated by the authors before submission. No AI-generated code was accepted without manual inspection.

## 3. Data & Synthetic Assets

- **Training and evaluation mazes**: 100% synthetically generated by local Python code (`ml/generate_mazes.py`) using deterministic randomized DFS with fixed seeds. No external, scraped, or proprietary datasets were used.
- **Model checkpoint** (`ml/checkpoints/best_model.pt`): Trained from scratch locally on synthetic data. No pretrained weights, foundation model APIs, or transfer learning were used.
- **BDH-CQ reference data** (`results/bdh_cq_reference.json`): Direct reproduction of published Table 5 from Kosowski et al. (2026), arXiv:2608.09888. Not generated by our code; clearly attributed.
