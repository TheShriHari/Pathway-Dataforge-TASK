## 1. Core Mathematical Proof: Receptive Field Growth & Saturation

### Judge Question:
> *"Why does accuracy rise rapidly from $K=1$ to $K=5$ and then plateau at $K=6..10$? Is this an artificial artifact of your training or an inherent geometric property?"*

### Defense Response:
It is an inherent geometric property of the convolutional architecture and grid diameter.

1. **Pointwise Input Encoder (`ml/model.py` Line 59-63)**:
   - The encoder uses a **$1 \times 1$ convolution**:
     $$\text{Encoder}(x) = \text{GELU}(\text{GroupNorm}(\text{Conv2D}_{1\times 1}(x)))$$
   - Because kernel size is $1$, **the receptive field before recurrent loops is exactly $1 \times 1$**. No spatial propagation across neighbors occurs in the encoder.

2. **Recurrent Core Spatial Expansion (`ml/model.py` Line 23-38)**:
   - The recurrent core is a shared-weight `ConvGRURecurrentCore` operating with **$3 \times 3$ convolutions** (padding = 1):
     $$r, z = \sigma\left(\text{Conv2D}_{3\times 3}(h_{\text{prev}}) + \text{Conv2D}_{1\times 1}(h_{\text{init}})\right)$$
     $$\tilde{h} = \tanh\left(\text{Conv2D}_{3\times 3}(r \odot h_{\text{prev}}) + \text{Conv2D}_{1\times 1}(h_{\text{init}})\right)$$
     $$h_{\text{next}} = (1 - z) \odot h_{\text{prev}} + z \odot \tilde{h}$$
   - Each application of the $3 \times 3$ convolution expands the spatial receptive field by $2$ cells in each dimension:
     $$\text{RF}(K) = 1 + 2K$$

3. **Receptive Field Progression Across Reasoning Loops**:
   | Reasoning Step ($K$) | Receptive Field Diameter ($\text{RF}$) | Covered Grid Neighborhood | Ability to Span $8 \times 8$ Grid |
   |:---:|:---:|:---:|:---|
   | $K = 1$ | $1 + 2(1) = 3$ | $3 \times 3$ | **Under-parameterized spatially**: Can only sense immediately adjacent corridors. Cannot connect distant start-to-goal paths. |
   | $K = 2$ | $1 + 2(2) = 5$ | $5 \times 5$ | Partial corridor connectivity. |
   | $K = 3$ | $1 + 2(3) = 7$ | $7 \times 7$ | Covers almost the entire subgrid. |
   | $K = 4$ | $1 + 2(4) = 9$ | $9 \times 9$ | **First step spanning the full $8 \times 8$ grid** ($\text{RF} > 8$). Global end-to-end topological path reaches $95\%$ solve rate. |
   | $K = 5$ | $1 + 2(5) = 11$ | $11 \times 11$ | **Full saturation**: Reaches peak accuracy ($97.0\%$ exact solve rate). Every cell can exchange latent information with any other cell and verify boundary conditions. |
   | $K = 6 \dots 10$ | $13 \times 13 \dots 21 \times 21$ | $\ge 13 \times 13$ | **Information-theoretic plateau**: Receptive field already exceeds grid diameter. Additional loops only fine-tune confidence on ambiguous edge boundaries, producing diminishing returns ($96\% - 97\%$). |

4. **Pointwise Readout Head (`ml/model.py` Line 69-72)**:
   - The readout head uses a **$1 \times 1$ convolution** followed by a sigmoid:
     $$\hat{y} = \sigma(\text{Conv2D}_{1\times 1}(h_K))$$
   - This guarantees that spatial integration **strictly** occurs inside the recurrent core loops $K$, proving the central claim.

## 3. Real Compute Latency vs. Loop Budget

### Judge Question:
> *"How did you measure compute cost? Is it just $K/10$?"*

### Defense Response:
- No. We explicitly benchmarked **real wall-clock inference latency** using high-resolution performance counters (`time.perf_counter()`) on CPU over 100 held-out test mazes:
  - $K = 1$: **$0.151$ ms / maze**
  - $K = 5$: **$0.573$ ms / maze**
  - $K = 10$: **$1.115$ ms / maze**
- The latency scales strictly linearly with $K$ ($\mathcal{O}(K \cdot D \cdot H \cdot W)$ FLOPs), while marginal accuracy gains decline to $0$ after $K=5$, demonstrating empirical diminishing returns.

## 4. Key Differences: Latent Recurrence vs. Autoregressive CoT

| Dimension | Autoregressive CoT (e.g. o1 / R1) | Latent Recurrence (e.g. BDH / ConvGRU) |
|---|---|---|
| **Bandwidth** | Natural language tokens emitted into context | Continuous tensor updates in fixed hidden state $h$ |
| **Memory Footprint** | Scales $\mathcal{O}(L^2)$ with token sequence length; KV-cache bloat | Constant $\mathcal{O}(D \cdot H \cdot W)$ memory across arbitrary $K$ |
| **Error Mode** | Hallucinated syntax, semantic drifting, verbose filler | Semantic drift bounded by gating mechanisms (GRU/residual norms) |
| **Inference Control** | Stop token heuristics or max token ceilings | Explicit loop count budget $K$ dialed per task difficulty |
