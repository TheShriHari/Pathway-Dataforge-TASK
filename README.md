# Inference-Time Scaling Explainer
> **DataForge x Pathway Hackathon Submission**  
> An educational, interactive web artifact proving inference-time latent compute scaling without verbalized natural-language reasoning tokens.

---

## 1. Central Claim

> **"Increasing the number of recurrent latent computation steps at inference time can improve reasoning accuracy without producing any additional natural-language reasoning tokens — but gains diminish and each extra step costs more compute/time."**

---

## 2. Educational Framing & Learning Objectives

- **Target Audience**: Machine learning researchers, practitioners, AI engineering students, and judges evaluating post-training and inference-time scaling paradigms.
- **Prerequisites**: Intuition regarding forward passes in neural networks, convolution/receptive fields, and graph pathfinding (BFS).
- **Core Learning Objectives**:
  1. Understand how **recurrent latent computation** expands the effective computational depth and receptive field of a shared-weight model without increasing parameter count.
  2. Contrast **continuous latent recurrence** with autoregressive **Chain-of-Thought (CoT)**:
     - *CoT*: Emits verbal tokens into context; quadratically scales attention memory, incurs KV-cache storage, and introduces compounding syntactic hallucinations.
     - *Latent Recurrence*: Refines representations in a fixed tensor manifold ($h_k = \text{Core}(h_{k-1}, x)$); zero token emission, constant memory footprint, pure tensor-level compute scaling.
  3. Observe empirical **diminishing returns**: accuracy climbs rapidly during initial iterations as spatial connectivity is established, then plateaus as the problem is solved.
  4. Compare local toy experiment dynamics with frontier published evidence from Pathway's **BDH-CQ** foundation model evaluated on ARC-AGI-1.

## 4. Empirical Scaling Results

Evaluated across $N=100$ held-out $8 \times 8$ mazes across reasoning steps $K = 1 \dots 10$:

| Reasoning Loops ($K$) | Exact Solve Rate (%) | Mean Path IoU (%) | Mean BCE Loss | Measured Latency (ms / maze) |
|:---:|:---:|:---:|:---:|:---:|
| **$K = 1$ (Low)** | 72.0% | 91.5% | 0.0816 | 0.151 ms |
| **$K = 2$** | 79.0% | 96.2% | 0.0392 | 0.261 ms |
| **$K = 3$** | 89.0% | 98.1% | 0.0223 | 0.331 ms |
| **$K = 4$** | 95.0% | 98.9% | 0.0160 | 0.424 ms |
| **$K = 5$ (Mid)** | **97.0%** | **99.0%** | 0.0162 | 0.573 ms |
| **$K = 6$** | 97.0% | 99.0% | 0.0175 | 0.660 ms |
| **$K = 7$** | 97.0% | 99.1% | 0.0173 | 0.771 ms |
| **$K = 8$** | 96.0% | 99.1% | 0.0161 | 0.881 ms |
| **$K = 9$** | 97.0% | 99.1% | 0.0147 | 1.060 ms |
| **$K = 10$ (High)** | 96.0% | 99.2% | 0.0128 | 1.115 ms |

- **Early Gain ($K=1 \to K=5$)**: $+25.0\%$ exact solve rate increase ($+7.5\%$ IoU gain) for $+0.422$ ms added latency.
- **Late Gain ($K=5 \to K=10$)**: $-1.0\%$ change (plateau reached, diminishing returns) while latency nearly doubles from $0.573$ ms to $1.115$ ms.

## 7. How to Reproduce from Scratch

### Prerequisites
- Python 3.10+ (Standard distribution recommended)
- Git

### Step-by-Step Reproduction
```powershell
# 1. Clone repository
git clone https://github.com/TheShriHari/Pathway-Dataforge-TASK.git
cd Pathway-Dataforge-TASK

# 2. Create and activate local virtual environment
python -m venv .venv
.venv\Scripts\activate   # On Linux/macOS: source .venv/bin/activate

# 3. Install dependencies
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install numpy scipy pytest matplotlib

# 4. Run automated test suite
pytest ml/tests site/tests

# 5. Run difficulty sweep (optional exploration)
python ml/sweep_difficulty.py

# 6. Train recurrent model with variable-loop curriculum
python ml/train.py

# 7. Evaluate on held-out test split and regenerate JSON
python ml/evaluate.py

# 8. Serve static web artifact locally
python -m http.server 8085 --directory site
# Open http://localhost:8085 in any modern browser
```
